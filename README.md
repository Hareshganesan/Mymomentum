## 🎯 The Core Philosophy: Why Momentum?

Most students preparing for software engineering placements fail not because they didn't solve problems, but because:
1. **The Forgetting Curve**: You solve 200 problems on LeetCode over 4 months, but when an interviewer asks for *Course Schedule* or *Trapping Rain Water*, you blank on the core intuition.
2. **Beyond Just DSA**: Placement interviews test **Core CS** (OS deadlocks, paging, DBMS B+ trees, ACID, networks handshakes), **System Design (LLD/OOP)**, and **Behavioral STAR questions**.
3. **Pipeline Chaos**: Tracking 30+ company online assessments, test dates, CTCs, and interview rounds across spreadsheets is tedious and overwhelming.
4. **Lack of Consistency**: Consistency beats talent every single time. Without daily momentum and streak protection, burnout wins.

**Momentum** brings all four pillars together into a unified, high-performance, distraction-free desktop application.

## ✨ Key Features & Placement Pillars

### 1. 🏠 Daily Placement Cockpit & Spaced Repetition Due Radar
- **Daily Readiness Radar**: Real-time Placement Readiness score (`0 - 100%`) and dynamic rank (*Novice Coder 🐣* ➔ *Pattern Apprentice ⚡* ➔ *OA Contender 🎯* ➔ *SDE Interview Ready 🚀* ➔ *Dream Offer Material 👑*).
- **Upcoming Drive Alert**: Prominently displays countdowns for upcoming Online Assessments (e.g. *"⚡ Amazon OA in 4 days"*).
- **Spaced Repetition Review Deck**: Every morning, problems due for revision based on SuperMemo intervals appear on the Home dashboard with one-click confidence reviews (`🔴 Hard (1d)`, `🟡 Good (3d)`, `🟢 Easy (7d)`).
- **Daily Targets & Streak Protection**: Set 2-3 deep work problem-solving targets every morning with grace-period streak freezing.

### 2. 🧩 Curated SDE Problem Sheet & Pattern Matrix
- **Curated High-Yield Problem Bank pre-loaded**:
  - Covers **14 essential patterns**: Arrays & Hashing, Two Pointers, Sliding Window, Monotonic Stack & Queue, Binary Search on Answer Space, Linked List, Trees & BST, Graphs (BFS/DFS, Dijkstra, Kahn's Algo), Dynamic Programming (1D, 2D, Knapsack), Greedy & Intervals, Heap/Priority Queue, and Bit Manipulation.
- **Problem Details & Intuition Vault**:
  - Time & Space complexities ($O(n)$, $O(1)$)
  - Target company tags (Google, Amazon, Microsoft, Meta)
  - Expandable **"Aha! Moment" Intuition Notes** & optimal code snippets
  - One-click launch direct to LeetCode/GeeksforGeeks
- **Multi-Filter & Instant Search**: Filter by Topic, Difficulty (Easy, Medium, Hard), Status (Solved, In Progress, Unsolved), or "Only Reviews Due".
- **Custom Problems**: Add any problem from your college tests or contests at any time.

### 3. 📚 Core CS & System Design Flashcards
- High-frequency interview cheat sheets covering:
  - 🖥️ **Operating Systems**: Coffman Deadlock Conditions, Process vs Thread, Paging & Virtual Memory, Mutex vs Semaphore vs Spinlock, Context Switching.
  - 🗄️ **DBMS & SQL**: ACID transactions, Clustered vs Non-Clustered B+ Tree indexes, Normalization (1NF - BCNF), WAL & MVCC.
  - 🌐 **Computer Networks**: DNS resolution flow, TCP 3-way handshake, TCP vs UDP, HTTP 1.1 vs HTTP/2 vs HTTP/3 (QUIC), TLS encryption.
  - 🧱 **OOP & System Design (LLD)**: 5 SOLID principles with code analogies, Singleton, Factory, and Observer design patterns.
- Interactive **"Show Detailed Answer"** flip-cards with high-yield interview buzzwords and "Mark Mastered" progress tracking.

### 4. 💼 Campus Placement Drive Kanban Pipeline
- Visual 5-stage pipeline for on-campus and off-campus recruitment:
  1. 📝 **Wishlist / Applied**
  2. 💻 **Online Assessment (OA)**
  3. 🛠️ **Technical Interview**
  4. 👔 **HR & Leadership**
  5. 🏆 **Offer Secured! 🎉**
- Tracks Company Name, Role, Package/CTC, Upcoming Test Date, and company-specific focus topics.
- One-click stage advancement (`OA ➔`, `Tech ➔`, `Offer! 🎉`) with celebratory golden confetti.

### 5. ⏱️ Timed Mock OA & Code Sprint Arena
- Practice under real online assessment time constraints:
  - Choose sprint duration: `30 Min Sprint`, `45 Min Interview Round`, or `60 Min Full OA`.
  - **"🎲 Pick Random Problem"** button pulls a challenge from your DSA sheet.
  - Monospace code editor with C++, Java, Python, and C# support.
  - Pre-submission interview self-evaluation checklist.
  - Input achieved Time and Space complexity ($O(...)$) upon completion.
  - Automatically records sprint history and awards placement activity points.

### 6. 👔 STAR Behavioral & HR Interview Vault
- Structured templates using the **STAR Framework** (*Situation, Task, Action, Result*):
  - *"Tell me about yourself (Elevator Pitch)"*
  - *"Describe a challenging technical bug and how you resolved it"*
  - *"A time you faced conflict or disagreement in a team project"*
  - *"Tell me about a time you failed or made a mistake"*
- Guided closing takeaways to deliver memorable, executive-ready answers.

### 7. 📊 Placement Readiness Matrix & 16-Week Heatmap
- **LeetCode / GitHub-Style 16-Week Activity Heatmap**: Visualizes your daily practice intensity.
- **Placement Readiness Trajectory**: Dynamic mathematical weighting of DSA solved, Core CS mastered, mock sprints completed, and applications tracked.
- **Difficulty Breakdown**: Easy, Medium, and Hard solved ratios.

### 8. 🏆 SDE Placement Gamification & Badges
- 12 unlockable placement achievements:
  - 🎯 *First Blood* (First task / problem solved)
  - ⚡ *Array & Two Pointers* (5 Array/Pointer problems)
  - 🌲 *Tree & Graph Master* (10 Tree/Graph problems)
  - 👑 *DP Conqueror* (15 high-frequency patterns)
  - 🧠 *CS Core Scholar* (5 Core CS cards mastered)
  - 💼 *Placement Hustler* (3 active campus drives tracked)
  - ⏱️ *OA Arena Veteran* (Complete a timed mock OA sprint)
  - 🔥 *Week of Steel* (7-day preparation streak)
  - 🚀 *Interview Ready* (Reach 70% Placement Readiness)
  - 🏆 *The Dream Offer!* (Secure an SDE placement offer)

## 🚀 How to Run

### Option 1: Direct Executable (Fastest)
Double-click:
```
Mymomentum\V3_exe\MyTodo.exe
```

### Option 2: Run via .NET 8 CLI
```powershell
cd Mymomentum\V3
dotnet run
```

### Option 3: Build & Publish Release
```powershell
cd Mymomentum\V3
dotnet publish -c Release -o ..\V3_exe
```

## 🛠️ Tech Stack & Architecture

- **Language & Framework**: C# 12 / WPF on [.NET 8.0](https://dotnet.microsoft.com/)
- **Design Pattern**: Clean MVVM-Lite (INotifyPropertyChanged, RelayCommand, Value Converters)
- **UI & Theme**: Custom Fluent Glassmorphism with Luxury Black & Gold color palette (`#080810`, `#D4AF37`, `#FFD700`), dynamic animated particle system, and drop shadows.
- **Persistence**: Zero-database local JSON storage located in `%LOCALAPPDATA%\MyMomentumPlacement\placement_data.json` with instant autosave.
- **Zero External Dependencies**: Pure WPF .NET standard libraries for maximum stability, instant launch times, and offline accessibility.
